# YouTube Transcript Extractor

Node.js (ESM) REST API + CLI that extracts YouTube transcripts, including manually uploaded and auto-generated captions, as plain text, JSON (with timestamps), SRT or VTT.

No third-party scraper package is used. Captions are fetched directly from YouTube (InnerTube player API, with a watch-page fallback), so there is no dependency to go unmaintained. The trade-off is in [Known limitations](#known-limitations).

## Setup

Requires Node.js 18.17+.

```bash
npm install
cp .env.example .env     # optional, all values have defaults
npm start                # http://localhost:3000
npm test                 # offline test suite (39 tests)
```

## REST API

### `POST /api/transcript`

| Field      | Type            | Default | Notes |
|------------|-----------------|---------|-------|
| `videoUrl` | string          | required | Any YouTube URL (watch, youtu.be, shorts, embed, live) or an 11-character video ID |
| `format`   | string          | `json`  | `json`, `text` (alias `txt`), `srt`, `vtt` |
| `lang`     | string or array | auto    | Priority list, e.g. `"en"`, `"bn,en"`, `["en","bn"]`. Omit or `"auto"` = the video's default language |
| `fallback` | boolean         | `true`  | If none of the requested languages exist, use the default track (reported via `fallbackUsed`). `false` returns `LANGUAGE_NOT_AVAILABLE` |
| `download` | boolean         | `false` | Return the raw file with `Content-Disposition` instead of a JSON envelope |

```bash
# JSON with timestamps, prefer Bengali then English
curl -X POST http://localhost:3000/api/transcript \
  -H "Content-Type: application/json" \
  -d '{"videoUrl":"https://youtu.be/dQw4w9WgXcQ","format":"json","lang":"bn,en"}'

# Download an SRT file
curl -X POST http://localhost:3000/api/transcript \
  -H "Content-Type: application/json" \
  -d '{"videoUrl":"https://youtube.com/shorts/dQw4w9WgXcQ","format":"srt","lang":"en","download":true}' \
  -OJ

# GET works too (handy in a browser)
curl "http://localhost:3000/api/transcript?videoUrl=dQw4w9WgXcQ&format=text&lang=en"
```

Success response:

```json
{
  "success": true,
  "data": {
    "videoId": "dQw4w9WgXcQ",
    "format": "json",
    "language": { "code": "en", "name": "English", "isAutoGenerated": false, "kind": "manual" },
    "requestedLanguages": ["bn", "en"],
    "fallbackUsed": false,
    "availableLanguages": [ { "code": "en", "name": "English", "isAutoGenerated": false, "kind": "manual" } ],
    "segmentCount": 42,
    "transcript": [ { "text": "...", "start": 0.32, "duration": 2.5, "timestamp": "00:00:00" } ]
  }
}
```

For `text`, `srt` and `vtt`, `transcript` is a string.

### `GET|POST /api/languages`

`{ "videoUrl": "..." }` returns the available caption languages and the video's default one.

### Errors

Every error has the same shape:

```json
{ "success": false, "error": { "code": "NO_CAPTIONS", "message": "...", "requestId": "..." } }
```

| HTTP | Code | Meaning |
|------|------|---------|
| 400 | `INVALID_REQUEST`, `INVALID_JSON`, `INVALID_URL`, `INVALID_FORMAT`, `INVALID_LANGUAGE` | Bad input |
| 403 | `VIDEO_PRIVATE`, `AGE_RESTRICTED`, `LOGIN_REQUIRED` | Video needs an account |
| 404 | `VIDEO_UNAVAILABLE`, `NO_CAPTIONS`, `LANGUAGE_NOT_AVAILABLE` | Deleted / no captions / language missing (lists what exists in `details.available`) |
| 413 | `PAYLOAD_TOO_LARGE` | Body over 10 KB |
| 429 | `RATE_LIMITED` | Your API rate limit **or** YouTube throttling / bot check (sets `Retry-After` when known) |
| 502 / 503 / 504 | `UPSTREAM_ERROR`, `PARSE_ERROR`, `UPSTREAM_BLOCKED`, `UPSTREAM_TIMEOUT` | YouTube misbehaved or blocked the request |
| 500 | `INTERNAL_ERROR` | Unexpected (details are logged, not leaked) |

## CLI

```bash
node extract.js <youtube-url-or-id> [options]

node extract.js https://youtu.be/dQw4w9WgXcQ                       # plain text to stdout
node extract.js dQw4w9WgXcQ -f srt -l en -o captions.srt           # SRT file
node extract.js "https://youtube.com/shorts/dQw4w9WgXcQ" -f json -l bn,en
node extract.js dQw4w9WgXcQ --list                                 # available languages
node extract.js dQw4w9WgXcQ -l fr --no-fallback                    # fail if French is missing
```

The transcript goes to stdout; status messages go to stderr, so piping is safe. Exit code is `0` on success, `1` on error, `2` on bad arguments.

## Configuration (`.env`)

See `.env.example`: `PORT`, `HOST`, `CORS_ORIGIN`, `TRUST_PROXY`, `RATE_LIMIT_WINDOW_MS`, `RATE_LIMIT_MAX`, `YT_TIMEOUT_MS`, `YT_RETRIES`, `CACHE_TTL_MS`, `CACHE_MAX_ENTRIES`. Set `TRUST_PROXY=1` behind a reverse proxy so rate limiting sees real client IPs.

## Known limitations

- **YouTube changes its internals.** This relies on undocumented endpoints. If every video suddenly fails, update `ANDROID_CLIENT_VERSION` in `src/services/youtubeClient.js` first.
- **Datacenter IPs are often blocked.** Running on a cloud host (AWS, GCP, a VPS) commonly triggers YouTube's bot check, surfacing as `RATE_LIMITED` or `UPSTREAM_BLOCKED`. It tends to work well from a home/residential connection. For cloud deployment you will likely need a residential proxy or another IP source.
- **Live end-to-end behaviour against YouTube was not tested** when this was built (the build sandbox could not reach YouTube). The URL parsing, caption parsing (all three formats), formatting, language selection, error mapping, caching and the full HTTP API are covered by the offline tests; the network layer has only been exercised for its failure path. Run `node extract.js <id> --list` on your machine as the first smoke test.
- Only captions YouTube already has are returned. There is no speech-to-text for videos without any captions.
# YouTube Transcript Extractor

এটি একটি Node.js প্রজেক্ট, যা YouTube ভিডিওর ক্যাপশন (ট্রান্সক্রিপ্ট) বের করে দেয়। ম্যানুয়ালি আপলোড করা ক্যাপশন এবং YouTube-এর অটো-জেনারেটেড ক্যাপশন, দুটোই কাজ করে। এটি দুইভাবে চালানো যায়: কমান্ড লাইন টুল (CLI) হিসেবে এবং REST API সার্ভার হিসেবে।

## মূল ফিচার

- watch, `youtu.be`, shorts, embed ও live লিংক অথবা ১১ অক্ষরের ভিডিও ID, সবকিছু সাপোর্ট করে
- আউটপুট ফরম্যাট: `text` (সাধারণ লেখা), `json` (সময়সহ), `srt` ও `vtt` (সাবটাইটেল ফাইল)
- ভাষার অগ্রাধিকার দেওয়া যায়, যেমন `bn,en`। কাঙ্ক্ষিত ভাষা না থাকলে ভিডিওর ডিফল্ট ভাষায় ফিরে যায়
- ভিডিওতে কোন কোন ক্যাপশন ভাষা আছে তার তালিকা দেখা যায়
- কোনো থার্ড-পার্টি স্ক্র্যাপার প্যাকেজ ছাড়াই সরাসরি YouTube থেকে ক্যাপশন আনে
- ক্যাশ, রেট লিমিট ও স্পষ্ট এরর কোড আছে

## CLI হিসেবে ব্যবহার

ভিডিওর ক্যাপশন ভাষার তালিকা দেখুন:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" --list
```

সাধারণ লেখা হিসেবে টার্মিনালে দেখুন:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw"
```

টেক্সট ফাইলে সেভ করুন:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" -o transcript.txt
```

সময়সহ SRT সাবটাইটেল ফাইল বানান:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" -f srt -o captions.srt
```

VTT ফাইল বানান:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" -f vtt -o captions.vtt
```

JSON (প্রতিটি লাইনের `timestamp` ও `start` সহ) বানান:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" -f json -o transcript.json
```

ভাষার অগ্রাধিকার দিন (বাংলা আগে, তারপর ইংরেজি):
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" -f json -l bn,en
```

ভাষা না পেলে ফলব্যাক না করে এরর দেখান:
```bash
node extract.js "https://www.youtube.com/watch?v=Rq1II71_Glw" -l fr --no-fallback
```

সব অপশনের সহায়তা দেখুন:
```bash
node extract.js --help
```

## সীমাবদ্ধতা

- শুধু YouTube-এ আগে থেকে থাকা ক্যাপশন পাওয়া যায়। ক্যাপশন নেই এমন ভিডিওর জন্য স্পিচ-টু-টেক্সট নেই।
- অনুবাদের সুবিধা নেই। `-l en` দিলে ইংরেজি ট্র্যাক না থাকলে ভিডিওর নিজের ভাষাই আসে।
- `text` ফরম্যাটে সময় থাকে না। সময় চাইলে `srt`, `vtt` বা `json` ব্যবহার করুন।
- YouTube-এর অনানুষ্ঠানিক এন্ডপয়েন্ট ব্যবহার করা হয়, তাই YouTube কিছু বদলালে টুল কাজ বন্ধ করতে পারে।
- ক্লাউড সার্ভার, VPS বা VPN-এর IP প্রায়ই ব্লক হয় (`RATE_LIMITED` বা `UPSTREAM_BLOCKED` এরর)। বাসার ইন্টারনেটে সাধারণত ঠিকমতো চলে।
- ভিডিও ডাউনলোড করে না, শুধু ট্রান্সক্রিপ্ট বের করে।
